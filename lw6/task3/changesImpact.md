## 1 
PictureDocument. Должна появится макрокоманда, которая сможет объединить в себе несколько команд (Удаление и разгруппировка)

CanvasController. Должен понимать работает ли он с группой или нет, исходя из этого менять свое поведение относительно выделения фигур.

EditorModel. Должен научиться создавать новую команду, искать фигуры внутри групп, разделять запросы найти группу по клику и найти фигуру в группе по клику

EditorShape. Сейчас представляет собой обёртку над IShape из Model. Должен научиться одновременно представлять из себя группу из оберток над IShape

Views. Должны понимать является ли сейчас EditorShape группой или нет, должны научиться обрабатывать случай, когда EditorShape - группа

## 2 
Пользователь нажимает ЛКМ по группе -> появляется событие передающееся от EditorWindow -> CanvasView -> CanvasController, CanvasController просит EditorModel выделить фигуру по координатам, группа выделяется.

Пользователь нажимает по вложенным фигурам выделенной группы, событие доходит до контроллера, контроллер просит отдельно выделить фигуру по координатам, EditorModel видит что точка принадлежит выделенной группе и ищет вложенную фигуру по этим координатам, если фигура оказалась группой, то ищет конкретную фигуру внутри неё, фигуры выделяются.

Пользователь нажимает кнопку Delete. событие доходит до контроллера, он просит EditorModel удалить выделенные фигуры. EditorModel создает нужную команду, она записывается в историю, выполняется, обновляется Model, обновляется EditorModel

## 3 

Изменится связь CanvasController и EditorShape, контроллер должен будет уметь определять является ли она группой или нет.

Изменится взаимодействие между View и EditorModel, View должна будет научиться определять является ли EditorShape группой или нет.

## 4
Текущий подход с EditorShape в виде обертки для IShape не позволяет поддержать семанитку Preview/Commit для вложенных групп.
EditorShape должен будет иметь возможность быть одновременно оберткой и над одной IShape, и над группой IShape

Классы EditorShape, IEditorShapeVisitor используются во Views, Views должны будут поддержать изменения, что EditorShape может представлять как отдельную фигуру так группу

Должна быть введена макрокоманда, которая обеспечит удаление фигур из группы и её возможную разгруппировку в виде атомарного действия

## 5

1. 
- as-is: Команда DeleteShapeCommand удаляет всю группу целиком 
- to-be: Макрокоманда представляет собой несколько команд, удаляющих отдельные компоненты группы, и расформирующие её при необходимости

2. 
- as-is:  Клик по фигуре группы выделяет группу целиком 
- to-be:  Клик по вложенной фигуры выделенной группы выделяет эту фигуру

3.
- as-is: Нельзя удалить вложенные в группу фигуры
- to-be: Группа поддерживает удаление вложенных фигур и распадается, если их <2
